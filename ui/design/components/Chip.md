A 20px pill that labels a state or a count, with keyboard-key variants for shortcuts.

**You provide:** a short label (one to three words) and, for states, an icon. Variants: neutral, `brand` (protected, upgraded), `warn` (not secure), `danger` (error).

- A chip never carries meaning by colour alone: add the icon and the word.
- Use `amaya-kbd` for key caps ("Ctrl", "K"), one per key, in the order pressed.
- Don't use chips as buttons; use a quiet button.
